# 배율 페이스 계산기

보스 배율(20분 동안 뽑아야 할 이상적인 딜량 %) 대비 **내 컨트롤이 몇 퍼센트인지**,
그리고 그 컨트롤로 **어느 배율까지 20분 컷이 되는지** 계산합니다.

👉 https://yh-yeop.github.io/BossPaceCalcul/

## 기능
- 클리어 타임 또는 20분 종료 시 남은 hp로 배율 대비 컨트롤(%)과 20분 컷 최소 배율 계산
- 목표 계산
  - **다른 배율이면?** 기준 컨트롤로 다른 배율 보스의 예상 클리어 타임 / 남은 hp
  - **목표 시간** 원하는 클리어 타임에 필요한 컨트롤과 최소 배율
- 보스별 배율: 20분 딜량(예: `350조`, `1.2경`)을 넣으면 보스 체력으로 배율을 자동 계산하고, 기준 컨트롤로 보스별 예상 클리어 타임 / 남은 hp 표시
  - 보스 이름 자동완성으로 선택 시 배율 자동 입력, 티어 필터·검색, 반감 전 딜량 옵션
  - 목록에 없는 보스는 체력을 직접 추가(LocalStorage)
- 공유 링크(쿼리 파라미터), 결과 카드 이미지 저장, 입력값 자동 저장

## 공식
- 이상 속도 = `배율 ÷ 20` %/분, 실제 속도 = `진행% ÷ 걸린 분`
- 컨트롤 = `실제 ÷ 이상`
- 배율 = `20분 딜량 ÷ 보스 체력 × 100` (반감 전 딜량 옵션 시 반감 보스는 딜량 ÷ 2)
- 최소 배율(T분 컷) = `2000 ÷ (컨트롤비율 × T)` — T = 20이면 `100 ÷ 컨트롤비율`
- 예상 시간 = `2000 ÷ (배율 × 컨트롤비율)` 분

전투 내내 같은 페이스를 유지한다는 가정의 참고용 계산입니다.

## 보스 체력 데이터
`data.js`에 있습니다. 출처는 나무위키 [메이플스토리/보스 몬스터/보스 티어](https://namu.wiki/w/메이플스토리/보스%20몬스터/보스%20티어) 7.1 값 목록(2026-09-26 조회)입니다.
카오스 파풀라투스 이상은 유저가 전투분석으로 측정한 값이고, 오버드라이브 패치 이후 주간 보스 체력은 실제와 다를 수 있습니다.
